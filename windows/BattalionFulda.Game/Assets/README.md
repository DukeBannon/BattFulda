# Windows visual assets

## `terrain_atlas_v1.png`

Generated with the built-in OpenAI image-generation tool on 2026-09-11. The
approved `docs/design/battalion_fulda_visual_target.png` was supplied as a style
reference. The atlas is deliberately versioned so later art direction can be
reviewed without overwriting prior assets.

Prompt:

> Production terrain texture atlas for a Windows operational wargame. Create
> exactly six equal top-down swatches in a 3-by-2 atlas: clear Central German
> grassland, cultivated patchwork fields, dense mixed woodland, a compact 1980s
> Hessian village, marshy wet ground, and rocky scrubby rough ground. Use
> restrained realistic hand-painted historical-wargame terrain, strict
> orthographic view, neutral overcast light, and a muted natural palette. Keep
> it readable inside 72-pixel hexes. Use narrow dark gutters. No text, labels,
> hexes, grid, roads, rivers, units, flags, UI, logos, watermark, cartoon forms,
> mobile-game styling, fantasy colors, isometric perspective, or conspicuous
> repeated focal objects.
