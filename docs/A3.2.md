# A3.2: In-game geographic map viewer

A3.2 closes the first geographic-map loop: SQLite-authored Point Alpha data is
compiled on Windows, copied to the boot disk, validated on the Amiga, and shown
in the tactical display.

## Delivered behavior

- Loads the 40 by 40 `point_alpha_map.bin` map at startup.
- Validates its magic, version, dimensions, record size, cell size, projected
  origin, record count, and per-layer values before use.
- Displays the full 20 by 20 kilometer map through a 20 by 11 cell viewport.
- Uses four elevation color bands for the current elevation-only source pass.
- Supports horizontal and vertical navigation with the mouse or WASD; narrow
  zones immediately outside the map edges provide continuous mouse panning.
- Shows terrain, elevation, and map coordinates in the information panel.
- Keeps database-backed unit selection and formation/state details working.
- Shifts the existing raster at a viewport boundary and redraws only the newly
  exposed row or column instead of repainting all 220 visible cells.

The eleven unit locations are deliberately illustrative. They test map
navigation and interaction but are not presented as a historical 1985 order of
battle or deployment.

## Visual direction

The tactical screen is map-first. Units use high-contrast faction colors and a
compact information panel remains beside the map. Future refinements may add a
small overview map and richer terrain symbols, while preserving immediate
readability on a stock A1200 rather than imitating modern high-resolution art.

## Build and run

```powershell
cd C:\Repositories\Games\BattFulda
.\build-amiga.ps1 -Clean -Test -Run
```

The build produces `build\amiga\battalion_fulda_a3.adf` with:

- `point_alpha_map.bin`
- `unit_types.bin`
- `formations.bin`
- `a2_scenario.bin`

The scenario filename retains the A2 format name because the database runtime
format is unchanged; the scenario record now references the production map.

## Manual acceptance

1. Confirm the initial view shows elevation bands and both faction colors.
2. Move with the mouse and WASD in all four directions. Hold the mouse in the
   narrow gap immediately beyond each map edge and confirm continuous panning.
3. Cross several viewport edges and confirm scrolling is materially faster.
4. Traverse far enough to see different elevation colors.
5. Select NATO and Warsaw Pact units and confirm their database information.
6. Cancel with right-click or Escape; Escape again exits.

Roads, rivers, settlements, woods, bridges, a minimap, unit movement, combat,
and historically reviewed deployment remain later milestones.
