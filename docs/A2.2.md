# A2.2: Database-driven Amiga runtime

A2.2 closes the external-data loop established in A2.1. SQLite remains a
Windows development tool; the stock Amiga 1200 runtime reads only compact,
validated binary files produced by Python.

## Runtime data path

```text
SQLiteStudio / SQLite
        |
        v
Python validation and compilation
        |
        v
map.bin + unit_types.bin + formations.bin + a2_scenario.bin
        |
        v
Amiga 1200 tactical display
```

The boot disk no longer includes the legacy A1 `units.bin` or `scenario.bin`.

## Delivered behavior

- Loads and validates all three relational database assets at startup.
- Rejects bad magic values, versions, record sizes, offsets, strings,
  coordinates, formation references, type references, or faction mismatches.
- Shows all eleven database-authored scenario units at their map positions.
- Uses the unit type faction to render NATO and Warsaw Pact counters.
- Shows the selected unit's scenario name and unit-type name.
- Shows its immediate formation and parent formation when one exists.
- Shows strength, descriptive morale, suppression, readiness, movement, and
  current terrain.
- Preserves mouse and WASD navigation, selection, cancellation, and vertical
  map panning from A1.
- Presents a readable error screen if runtime data cannot be loaded safely.

Morale bands are a presentation rule over the database's 0-100 value:

- 85-100: Confident
- 70-84: Steady
- 50-69: Shaken
- 0-49: Broken

## Build and test

```powershell
cd C:\Repositories\Games\BattFulda
.\build-amiga.ps1 -Clean -Test
```

This must pass all host-side data tests, compile the 68020 executable without
errors, and produce `build\amiga\battalion_fulda_a2.adf` containing exactly the
four runtime data files listed above.

Run it in the configured A1200 emulator:

```powershell
cd C:\Repositories\Games\BattFulda
.\build-amiga.ps1 -Clean -Test -Run
```

## Manual acceptance

1. Confirm eleven counters are visible across the full map while panning.
2. Move with both the mouse and WASD.
3. Select NATO and Warsaw Pact units with left-click or Return.
4. Confirm the displayed unit type, formation hierarchy, and state match the
   SQLiteStudio records.
5. Cancel with right-click or Escape; Escape again exits.

Movement, combat, command effects, fog of war, and turn resolution remain
outside A2.2.

## Known limitation

Crossing a vertical viewport boundary redraws all 220 visible map cells. This
is correct but visibly slow on the stock A1200 target. A later display milestone
should scroll or copy the existing raster and draw only the newly exposed row.
