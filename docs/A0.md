# A0: Amiga 1200 Foundation

A0 validated the replacement production platform before gameplay development
continued. The baseline is a stock Amiga 1200 with a 68020, AGA, and 2 MB of
Chip RAM. It was completed at Git commit `fa9f4c4`; the current build script now
builds the succeeding A1 milestone.

## Historical build

To reproduce A0, check out commit `fa9f4c4`. On the current branch, follow
`docs\A1.md` instead.

```powershell
.\build-amiga.ps1
```

Build and launch the bootable test disk in the existing WinUAE A1200
configuration:

```powershell
.\build-amiga.ps1 -Run
```

The PowerShell build discovers the compiler supplied by the installed Amiga
Debug VS Code extension. VS Code remains optional; the script invokes the
compiler, ELF-to-Amiga conversion, and disk builder directly.

## Acceptance test

- An A1200 custom screen opens and shows the A0 input grid.
- The native Amiga mouse moves the highlighted cell.
- WASD moves the same highlighted cell.
- The left mouse button changes the status to `CLICK`.
- Escape closes the program cleanly.

The existing C64 source and `build.ps1` remain available as the preserved D1
prototype.
