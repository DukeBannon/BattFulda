# A3.1: Geographic map foundation

A3.1 establishes the production map data foundation used by the A3.2 runtime.
The Point Alpha-Huenfeld corridor map is ready for terrain-layer development
and is now attached to the demonstration scenario.

## Geographic extent

- Map key: `point_alpha_corridor`
- Grid: 40 by 40 cells
- Cell size: 500 meters
- Ground area: 20 by 20 kilometers
- CRS: ETRS89 / UTM zone 32N (EPSG:25832)
- Southwest origin: E 554000 m, N 5610000 m
- Northeast limit: E 574000 m, N 5630000 m
- Game coordinate `(0, 0)` is the northwest cell

This extent is intended to cover the northern Fulda corridor around Huenfeld,
Rasdorf, Point Alpha, and the former Inner German Border. Exact feature
placement will be checked during the road, settlement, hydrography, and 1985
historical-review passes.

## Source and attribution

Elevation comes from the German Federal Agency for Cartography and Geodesy's
DGM200 product. The official 200-meter samples are averaged into each
500-meter game cell.

```text
GeoBasis-DE / BKG 2020 (data modified)
Datenlizenz Deutschland - Namensnennung - Version 2.0
```

Product page:

https://gdz.bkg.bund.de/index.php/default/digitale-geodaten/digitale-gelandemodelle/digitales-gelandemodell-gitterweite-200-m-dgm200.html

The national source archive is not committed. Download and reproduce the map
seed with:

```powershell
cd C:\Repositories\Games\BattFulda
curl.exe -L "https://daten.gdz.bkg.bund.de/produkte/dgm/dgm200/aktuell/dgm200.utm32s.gridascii.zip" -o ".\build\dgm200.utm32s.gridascii.zip"
python .\tools\build_fulda_map.py .\build\dgm200.utm32s.gridascii.zip
```

The checked-in `data\maps\point_alpha_cells.csv` is the compact, reviewable
derived source. Regeneration currently yields elevations from 238 to 691
meters and is byte-for-byte deterministic.

## Relational map model

Schema version 2 adds:

- `terrain_type`: stable runtime IDs and future cover/concealment ratings
- `map_source`: source, date, license, attribution, and transformation notes
- `map_cell`: one record per cell with independent layers for base terrain,
  elevation, road class, river class, settlement level, and bridge presence
- Projected-coordinate and review-status metadata on `map`

Layer values are deliberately separate. A wooded cell can also contain a road,
river, settlement, or bridge.

All 1,600 initial cells use base terrain `clear`, have zeroed feature layers,
and are marked `elevation_only`. This prevents modern or invented features from
being mistaken for reviewed 1985 terrain.

## SQLiteStudio review

After reopening or refreshing `data\database\battfulda.sqlite`, inspect:

- `map` for grid dimensions and projected bounds
- `map_source` for provenance and licensing
- `terrain_type` for the terrain vocabulary
- `map_cell` for the 1,600 editable layered records

Useful SQLite queries:

```sql
SELECT map_key, width, height, cell_size_m, geographic_status
FROM map ORDER BY map_id;

SELECT MIN(elevation_m), MAX(elevation_m), ROUND(AVG(elevation_m), 1)
FROM map_cell WHERE map_id = 1;

SELECT source_status, COUNT(*)
FROM map_cell WHERE map_id = 1 GROUP BY source_status;
```

After making and committing edits in SQLiteStudio, save them back to the
reproducible map seed and readable database exports:

```powershell
cd C:\Repositories\Games\BattFulda
python .\tools\manage_database.py save-map
python .\tools\manage_database.py export
python .\tools\manage_database.py validate
```

`save-map` is intentionally explicit: ordinary builds never overwrite the
editable map seed.

## Compact Amiga format

`generated\point_alpha_map.bin` uses:

- Magic `BFMP`
- Version 1
- Map ID, width, height, record size, 500-meter cell size
- 32-bit UTM easting and northing for the southwest origin
- 1,600 seven-byte records in row-major order
- Per record: terrain ID, signed 16-bit elevation, road class, river class,
  settlement level, and bridge flag
- Big-endian multibyte values for the 68020

The compiled file is 11,219 bytes. A3.2 copies it to the boot disk and loads it
directly on the Amiga.

explicit source attribution, deterministic exports, the 11,219-byte compiled
map, all host tests passing, and a successful A3.2 Amiga build.
