# W0: Windows visual proof

> W0 is preserved as the Windows visual-foundation milestone. W1 supersedes its
> map geometry and data pipeline with the production 250-meter battlefield.

W0 establishes the Windows production runtime in C# and demonstrates that the
approved visual target can be implemented with actual Battalion: Fulda data.
It carries forward the SQLite, CSV, Python, map, formation, scenario, and unit
work established during early prototyping.

## Production baseline

- Windows 10 or later
- C# and .NET 10
- Visual Studio Community 2026 as the recommended IDE
- PowerShell and `dotnet` as the authoritative build path
- Windows Forms application shell with a custom double-buffered flat-top hex battlefield
- SQLite remains the authoritative design database

No general-purpose game engine is required.

## Acceptance target

W0 is complete when a 1920 by 1080 game window presents a polished version of
the approved design using real Point Alpha terrain and scenario units:

- a visible hex cursor moved by WASD or the arrow keys, with Enter selection
  and automatic camera following;
- smooth mouse edge-scrolling and left-button map dragging plus
  cursor-centered wheel zooming;
- cached battlefield and minimap layers so navigation does not rebuild static
  terrain artwork on every scroll tick;
- conventional flat-top operational-wargame hexes with accurate six-neighbor
  selection and connected map features;
- finished Central European terrain artwork and connected transport/water layers;
- database-authored six-direction road and waterway topology so nearby features
  do not create false intersections;
- visibly distinct fordable streams, minor rivers, and major rivers, with
  bridges and authored fords handled as local crossing features;
- readable NATO-style counters, selection states, stacking, and overlays;
- a compact unit/terrain inspector and command strip;
- combined road/water/bridge feature reporting for multi-feature hexes;
- a functional minimap with a clipped viewport indicator plus click-and-drag
  camera navigation;
- stable rendering without progressive row or column repainting;
- responsive selection with data originating in the existing data pipeline.

## First foundation slice

The initial C# project loads the existing 40 by 40 Point Alpha CSV map and A2
scenario-unit export. It establishes the final screen regions, clipped map
renderer, counter layer, inspector, minimap, mouse drag, wheel zoom, keyboard
panning, and selection behavior. Authored production artwork will replace the
foundation textures without changing game data or interaction code.
