# A1: Map and unit interaction

A1 replaces the A0 input grid with the first recognizable tactical display.
It retains the stock Amiga 1200 baseline: 68020, AGA, and 2 MB of Chip RAM.

## Delivered slice

- The editable JSON map, scenario, and unit fixtures are validated by Python.
- `map.bin`, `scenario.bin`, and `units.bin` are copied onto the bootable ADF.
- The Amiga executable loads and validates those files through AmigaDOS.
- Five terrain types use a dedicated military palette and visual treatment.
- NATO and Warsaw Pact units use distinct colors and map symbols.
- Mouse and WASD move one shared world-map cursor.
- WASD pans vertically across the 20 by 15 map when the cursor crosses the
  20 by 11 viewport boundary.
- Left-click or Return selects a unit and opens its information panel.
- Right-click or Escape cancels a selection. Escape exits when no unit is
  selected.

## Build and run

```powershell
cd C:\Repositories\Games\BattFulda
.\build-amiga.ps1 -Clean -Test -Run
```

The outputs are `build\amiga\battalion_fulda_a1.exe` and
`build\amiga\battalion_fulda_a1.adf`.

## Acceptance test

1. Confirm the Fulda terrain map and tactical panel appear.
2. Move the yellow cursor with the mouse and WASD.
3. Select the blue NATO `N` at map position 5,10.
4. Confirm the panel reports NATO armor, strength 10, movement 6, and terrain.
5. Cancel with right-click or Escape.
6. Select the red Warsaw Pact `W` at map position 15,4 and confirm its panel.
7. Move down with `S` to confirm the viewport pans through map row 14.
8. With no unit selected, press Escape and confirm a clean return to Workbench.

Movement orders, pathfinding, combat, AI, sound, and saved games remain outside
the A1 scope.
