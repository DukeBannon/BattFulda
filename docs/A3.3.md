# A3.3: Recognizable terrain pass

> Historical milestone note: this document describes the preserved 500-meter
> Amiga terrain pass. The Windows W1 production map now implements the planned
> 250-meter regular-hex conversion described in `W1.md`.

A3.3 adds the first real landscape features to the Point Alpha map while
preserving the editable relational-data workflow. It is a geographic reference
pass, not yet a reconstruction of the terrain on a particular day in 1985.

## Sources and status

Elevation continues to come from BKG DGM200. Roads, waterways, woodland,
settlements, standing water, marsh, rough ground, and transport structures are
clipped from the official BKG DLM250 Web Feature Service in EPSG:25832.

```text
GeoBasis-DE / BKG 2025 (data modified)
Datenlizenz Deutschland - Namensnennung - Version 2.0
```

Service page:

https://gdz.bkg.bund.de/index.php/default/webdienste/digitale-landschaftsmodelle/wfs-digitales-landschaftsmodell-1-250-000-wfs-dlm250.html

DLM250 has a modern reference date. Its features are marked `draft`; they must
be compared with period maps before the production scenario is described as a
1985 reconstruction. The database records both BKG sources and their dates,
licenses, transformation notes, and attribution.

## Reproducing the map

The national elevation archive and clipped WFS responses remain ignored build
inputs. Recreate the checked-in editable cell seed with:

```powershell
cd C:\Repositories\Games\BattFulda
curl.exe -L "https://daten.gdz.bkg.bund.de/produkte/dgm/dgm200/aktuell/dgm200.utm32s.gridascii.zip" -o ".\build\dgm200.utm32s.gridascii.zip"
.\tools\download_fulda_features.ps1
python .\tools\build_fulda_map.py .\build\dgm200.utm32s.gridascii.zip --dlm250-dir .\build
python .\tools\manage_database.py init --force
```

For this preserved milestone, the Python conversion used only the standard
library. Lines were sampled at no
more than 100-meter intervals and assigned to the 500-meter game grid. Their
ordered paths are retained as reciprocal six-direction hex connection masks,
preventing unrelated roads or waterways in adjacent cells from forming false
intersections. Polygon layers are sampled within each cell. Base-terrain
priority is water, settlement, marsh, woodland, rough, then clear. At the
500-meter draft scale, nearby roads and waterways could still quantize
into the same cell even when they do not intersect geographically. The planned
250-meter conversion was completed in W1; it retains original vector paths and
derives edge topology and crossing locations without deleting connected roads.

## Current result

- 1,600 cells total
- 675 woodland cells
- 98 settlement/urban cells
- 690 cells with roads
- 387 cells with watercourses
- 9 cells with mapped transport structures
- 294 cells still containing elevation alone

Counts describe the current conversion and are useful regression checks, not
claims of final game balance or 1985 historical accuracy.

## Amiga presentation

The A1200 viewer connects road and river marks to matching neighboring cells.
Woodland uses a denser pattern, settlements use several building blocks, and
transport structures receive a contrasting bridge mark. Elevation shading,
fast raster scrolling, mouse edge-panning, WASD navigation, and database-backed
unit selection remain in place. The tactical panel presents compound cell
descriptions such as `CLEAR/ROAD/STREAM`, reflecting independent map layers
rather than reporting only the base terrain.
